# 민수 버전확인

Launch Kit 저장소 기준 환경·프레임워크·라이브러리 버전 목록. 팀원 노트북 호환성 맞추기용.
기준일 2026-10-24, 저장소 `main` 브랜치의 `package-lock.json`과 민수 Mac에 실제 설치된 값에서 뽑음.

## 1. 실행 환경 (팀원 노트북에서 맞춰야 하는 것)

| 항목 | 버전 | 비고 |
|---|---|---|
| Node.js | **24.2.0** | 저장소에 `engines`/`.nvmrc`가 없어 강제되진 않음. 20 이상이면 동작, 24 권장 (worker Docker 이미지도 node:24) |
| npm | 11.3.0 | lockfile v3 → npm 7 이상이면 됨 |
| ffmpeg | 9.0.2 (Homebrew) | worker 실행할 때만 필요. Homebrew 기본 빌드에는 자막 필터 `drawtext`가 없어 로컬 렌더는 자막 없이 나옴 (코드가 자동 감지). Debian 패키지 ffmpeg 5.1에는 있음 |
| Supabase CLI | 2.121.0 | 로컬 DB(`supabase start`) 띄울 때만 필요. Docker 필요 |
| Docker | 28.0.0 | 로컬 Supabase 전용 |
| macOS | 27.0.1 | 참고 |

설치 명령 (macOS):

```bash
brew install node@24 ffmpeg supabase/tap/supabase
npm ci        # npm install 대신 ci를 써야 아래 "실제 설치" 버전과 동일하게 맞춰짐
```

## 5. 배포 환경

| 구성 | 위치 | 버전·베이스 |
|---|---|---|
| 웹 (Next.js + API) | Vercel, 프로젝트 `launch-kit` (팀 test-m) | Node 24.x 런타임 |
| worker | 현재 민수 Mac에서 `npm run worker` (Fly 앱은 2026-10-24 삭제) | Docker 재배포 시 `worker/Dockerfile`: node:24-slim + Debian ffmpeg 5.1 + fonts-dejavu-core |
| DB·Storage | Supabase 클라우드 | 버킷 `launches` (공개) |

## 7. 확인 명령

```bash
node -v && npm -v && ffmpeg -version | head -1
npm ci && npm run typecheck && npx next build
```
